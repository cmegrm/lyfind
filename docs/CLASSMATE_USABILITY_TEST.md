# LyFind: 10-minute classmate usability exercise

This is a prepared worksheet, not evidence that classmates have already tested the site. Ask three classmates who have not worked on the interface to try it individually. Use the local testing workspace and fictional details. Do not coach them through the buttons; say “What would you try next?” when they pause.

Open the quiet three-dot control and choose Student 2. Note the starting time. Another group member observes and records the results.

| Task | What to observe |
|---|---|
| Start a lost report using a fictional umbrella, select its category/color/place, type details, then close it. Resume the unfinished report. | Can they find the draft? Do they understand it is not submitted? |
| Review the report. Edit one detail and return to the review, then submit it. | Can they distinguish Review from Submit? Is the summary useful? |
| Read Your next step and explain what they should do now. | Do they understand that CSA checks matches and they should wait for an invitation? |
| Switch to Professor and submit a found report. Explain what happens before it can be claimed. | Do they understand physical receipt at CSA is required? |
| Open Accessibility. Try larger text, higher contrast, and reduced motion. Navigate using Tab, Enter/Space, and Escape. | Can they read the form and find keyboard focus? Does closing settings preserve the draft? |

Optional group-led recovery exercise: after the review screen appears, temporarily disconnect this computer's network or stop its local server, then try submitting. Restore the connection/server and press Try again. Confirm there is one report. Do this only in the testing workspace. The automated browser exercise additionally simulates a saved report whose reply was lost.

For each task, record: finished unaided / finished with help / did not finish; approximate time; where they paused; and what they expected to happen. Do not record account passwords or personal item details.

Afterward ask:

1. Which label or step was hardest to understand?
2. Did you ever think a draft was already submitted?
3. What should LyFind make easier next?
